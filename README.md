# 프랭클린 플래너 APK

바탕화면 위젯에서 오늘 할 일을 바로 추가하고 체크하는 안드로이드 앱입니다.

## 다운로드 (최신 버전: 5)

**[FranklinPlanner.apk 받기](https://github.com/neotech67etkim/franklin-planner-releases/raw/main/FranklinPlanner.apk)**

## 설치 / 업데이트
1. 위 링크로 APK를 받아 설치합니다. ("출처를 알 수 없는 앱" 허용이 필요할 수 있습니다)
2. 바탕화면 빈 곳을 길게 눌러 **위젯 → 프랭클린 플래너 "오늘 할 일"** 을 추가합니다.
3. 새 버전이 나오면 같은 링크로 받아 그대로 덮어 설치하면 됩니다. 앱을 지우지 않으면 할 일 데이터는 유지됩니다.

## 주요 기능 (버전 4)
- **오늘**: A·B·C 우선순위 업무 목록(A1, A2 …), 상태 기호(✓ 완료 · ● 진행 중 · ◯ 위임 · ✕ 삭제 · → 이월), 일정, 일일 기록, 못 끝낸 일 오늘로 이월
- **주간**: 7일 한눈에, 자기 쇄신(톱날 갈기) 4가지, 역할별 이번 주 목표
- **월간**: 달력, 이번 달 목표·메모, 이달 일정
- **가치·목표**: 개인 사명서, 지배 가치, 역할, 장기 목표 → 오늘 할 일로 보내기
- **백업**: ⋮ 메뉴 → 백업 파일로 내보내기 / 불러오기

## 위젯 사용법
- 바탕화면을 길게 눌러 위젯 → **"오늘 일정·할 일"** 추가 (기본 4×3, 크기 조절 가능)
- 위쪽 **"할 일 추가…"** 를 누르면 입력창이 바로 열림. 입력 후 완료(Enter)하면 추가되고 계속 입력 가능
- 아래 목록에 **오늘 일정**(지난 일정은 흐리게)과 **우선순위 할 일**이 함께 표시
- 할 일 줄을 누르면 체크 / 해제, 날짜를 누르면 앱 열기

### 갤럭시 Z 플립 바깥 화면(커버 화면)에 띄우기
1. 설정 → 커버 화면(또는 플렉스 윈도우) → 위젯 에서 **프랭클린 플래너**를 켭니다.
2. 목록에 없으면 Good Lock 앱의 **MultiStar → "I ♡ Galaxy Foldable" → 커버 화면 위젯**에서 추가할 수 있습니다.

갤럭시 Z 폴드는 바깥 화면도 일반 홈 화면이라 위와 같이 위젯을 추가하면 됩니다.
